# 🎹 Утреннее пианино для Лены

Мини веб-игра для поднятия утреннего настроения: пожелания, 7 мелодий на выбор и своя финальная анимация для каждой.

## Как играть
1. На первом экране — утренние пожелания, кнопка «Включить музыку утра».
2. Выбери мелодию. Над клавишами плывут пузырьки с нотами, нужная клавиша светится.
3. Кнопка «🎧 Послушать» проигрывает мелодию целиком с подсветкой клавиш.
4. В конце запускается анимация, мелодия звучит ещё раз, появляются звёзды (★★★ — до 2 ошибок) и пожелание.
   Нажатие на экран повторяет анимацию.

## Мелодии и анимации
| # | Мелодия | Композитор | Финал |
|---|---------|-----------|-------|
| 1 | Утро ☀️ | Григ | Рассвет над холмами, птицы |
| 2 | Ода к радости 🎆 | Бетховен | Салют с сердечками |
| 3 | Колыбельная 🌙 | Брамс | Звёзды и луна, переход в утро |
| 4 | Весна 🌸 | Вивальди | Растущие цветы и лепестки |
| 5 | Мерцай, звёздочка ⭐ | Моцарт | Созвездие-сердце с именем «Лена» |
| 6 | Менуэт соль мажор 🦋 | Из тетради А. М. Бах | Бабочки |
| 7 | К Элизе 🌹 | Бетховен | Сердце из лепестков роз «Я тебя люблю» |

**Главный финал** — когда сыграны все 7 мелодий: Маленький принц и роза встречают рассвет на своей планете
(под «Утро» Грига). Пересмотреть можно кнопкой «🌅 Рассвет с Маленьким принцем» в меню.

## Структура
```
morning-piano/
├── index.html        — разметка всех экранов
├── css/style.css     — оформление (стекло, градиенты, клавиатура, адаптив под iPhone)
└── js/
    ├── audio.js      — синтез пианино на Web Audio API (с реверберацией)
    ├── songs.js      — ноты мелодий, пожелания, цвета
    ├── game.js       — клавиатура, подсказки, прогресс, «Послушать»
    ├── finale.js     — 7 анимаций на canvas
    └── app.js        — экраны, меню, звёзды (сохраняются в localStorage)
```

## Как добавить свою мелодию
В `js/songs.js` добавь объект в `SONGS`. Ноты записываются как `Нота+Октава:доли`,
например `E4:1 D#4:.5 C5:2`. Клавиатура сама подстроится под диапазон мелодии.
Поле `anim` — одно из: `sunrise`, `fireworks`, `lullaby`, `spring`, `constellation`, `butterflies`, `roseHeart`, `littlePrince`.

## Запуск
Открыть `index.html` в браузере или выложить на GitHub Pages.
На iPhone звук включается после первого касания (так требует Safari). Беззвучный режим на iPhone может глушить звук из браузера.
